# WEB COMPUTER 1.0

A Windows 11-inspired browser desktop built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. For offline/PWA support, run it from a local HTTP server.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this project (keep the folder structure).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for deployment and open the Pages URL.

## Included
- Animated boot screen
- Desktop, Start menu and taskbar
- Draggable, minimizable, maximizable app windows
- File Explorer (local virtual files/folders)
- Notes with persistent local storage
- Calculator
- Terminal with built-in commands
- Settings, accent colors and custom wallpaper
- Quick settings, brightness and volume controls
- Calendar, browser launcher and About
- Basic service worker/offline cache

## Notes
This is a browser-based desktop simulation, not a real operating system. Data is stored in the current browser profile on the current device. Clearing browser site data can remove it. Browser access to local files and hardware is restricted by design.
